# Daniela Renteria — Portfolio

A bilingual, responsive developer portfolio built with React, Vite, and TypeScript.

## Requirements
- Node.js 18+ (Node.js 20 LTS recommended)
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Before publishing
1. Replace the GitHub and LinkedIn profile URLs in `src/App.tsx`.
2. Replace `hello@example.com` with your professional email.
3. Add your real CV PDF under `public/` and create a download link.
4. Review every skill and project description. Remove tools or claims you cannot confidently explain.
5. Add project screenshots and public demo/repository links only when available.
6. Confirm dates and role descriptions in the Experience section.

## Project structure

```text
src/
  App.tsx       Main page and reusable section markup
  content.ts    English/Spanish copy, project data, and skills
  types.ts      TypeScript types
  styles.css    Responsive visual design
  main.tsx      React entry point
```

## Notes
- The professional system and integration entries are case-study placeholders, not links to confidential company systems.
- The AI document-search entry is intentionally conservative. Confirm the exact tools and architecture before publishing technical claims.
- Node.js is shown as a skill placeholder; keep it only if you are comfortable discussing your level honestly.
